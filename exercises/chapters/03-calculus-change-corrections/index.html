Corrections: Calculus and Change

Foundation

1. Differentiate

$$\boxed{5x^4-6x}.$$

2. Differentiate

Rewrite $4x^3-x^{-1}$, giving $\boxed{12x^2+x^{-2}}$.

3. Differentiate

Expand or use the product rule: $(x+1)(x^2-2)=x^3+x^2-2x-2$, so $\boxed{3x^2+2x-2}$.

4. Differentiate

$$\frac{d}{dx}(x^2e^x)=\boxed{e^x(x^2+2x)}.$$

5. Gradient

$$y'=3x^2-4,$$ so at $x=2$, $\boxed{8}$.

6. Stationary points

$$y'=3x^2-3=0\implies x=\pm1.$$ The points are $\boxed{(-1,2)\text{ maximum},(1,-2)\text{ minimum}}$.

7. Integrate

$$\boxed{2x^3-2x^2+x+C}.$$

8. Integrate

$$\boxed{\ln|x|+C}.$$

9. Evaluate

$$\int_0^2(3x^2+1)\,dx=[x^3+x]_0^2=\boxed{10}.$$

10. Tangent

At $x=1$, $y=4$ and $y'=2x+3=5$. Therefore $\boxed{y-4=5(x-1)}$, or $\boxed{y=5x-1}$.

Core technique

11. Stationary points

$$y'=3(x-1)(x-3).$$ The points are $(1,6)$ and $(3,2)$. Since $y''=6x-12$, $\boxed{(1,6)\text{ is a maximum},(3,2)\text{ a minimum}}$.

12. Increasing intervals

$$f'(x)=3(x-3)(x+1).$$ It is positive outside the roots, so $\boxed{x<-1\text{ or }x>3}$.

13. Area

On $[0,1]$, $x\ge x^2$, so $$\int_0^1(x-x^2)\,dx=\frac12-\frac13=\boxed{\frac16}.$$

14. Evaluate

$$\int_1^e\frac1x\,dx=[\ln x]_1^e=\boxed1.$$

15. Find $y$

$$y=2x^2-3x+C.$$ Using $y(1)=2$ gives $C=3$, so $\boxed{y=2x^2-3x+3}$.

16. Differentiate

$$\boxed{10(2x+1)^4}.$$

17. Differentiate

$$\boxed{\frac{2x}{x^2+1}}.$$

18. Normal

The tangent gradient at $(1,1)$ is $2$, so the normal gradient is $-1/2$. Thus $\boxed{y-1=-\frac12(x-1)}$.

19. Maximum

$$A=x(10-x)=10x-x^2,$$ so $A'=10-2x=0$ at $\boxed{x=5}$.

20. Rest

$$s'(t)=3(t-1)(t-3),$$ hence $\boxed{t=1,3}$.

TMUA challenge

21. Area

Intersections are $x=\pm2$: $$\int_{-2}^{2}(4-x^2)\,dx=\boxed{\frac{32}{3}}.$$

22. Minimum

$$f'(x)=1-\frac4{x^2}=0\implies x=2.$$ Since $f''(2)=1>0$, the minimum is $\boxed4$.

23. Increase/decrease

$$f'(x)=3(x-1)(x-3).$$ Increase on $\boxed{(-\infty,1)\cup(3,\infty)}$ and decrease on $\boxed{(1,3)}$.

24. Tangents

At $(a,a^2)$, tangent is $y-a^2=2a(x-a)$. Setting $(0,-1)$ on it gives $-1-a^2=-2a^2$, so $a^2=1$. The tangents are $\boxed{y=2x-1}$ and $\boxed{y=-2x-1}$.

25. Integration by parts

Take $u=\ln x$, $dv=x\,dx$. Then $$\int_0^1x\ln x\,dx=\left[\frac{x^2}{2}\ln x-\frac{x^2}{4}\right]_0^1=\boxed{-\frac14}.$$

26. Stationary points

$$y'=4x(x^2-2),$$ so $x=0,\pm\sqrt2$. Values are $(0,0)$ and $(\pm\sqrt2,-4)$. Since $y''=12x^2-8$, $\boxed{(0,0)\text{ is a maximum};(\pm\sqrt2,-4)\text{ are minima}}$.

27. Maximum rectangle

For half-width $x$, height $12-x^2$ and area $A=2x(12-x^2)$. Then $A'=24-6x^2=0$, so $x=2$. The maximum area is $\boxed{32}$.

28. Number of roots

$f'(x)=3(x^2-1)$, so the cubic has a local maximum at $x=-1$ and minimum at $x=1$. Their values are $3$ and $-1$, respectively, so the graph crosses the axis three times: $\boxed{3}$ real roots.

29. Find $f$

$$f(x)=\ln(x^2+1)+C.$$ Since $f(0)=4$, $C=4$, so $\boxed{f(x)=\ln(x^2+1)+4}$.

30. Prove

$$(x-1/x)^2\ge0\implies x^2+\frac1{x^2}\ge2.$$ Equality holds when $x=1/x$, so for positive $x$, $\boxed{x=1}$.
