# AGENTS.md

## Project purpose
This workspace is a TMUA (Test of Mathematics for University Admission) study plan. Most work here is planning, scheduling, notes, and resource tracking rather than application code.

## Working conventions
- Keep the study plan practical and realistic: focus on revision balance, timed practice, and weak-topic recovery.
- Prefer plain, readable Markdown for plans and notes unless a file format is explicitly required.
- Preserve the existing structure of any study-plan documents; avoid renaming core files without a clear reason.
- Treat PDFs and downloaded resources as reference material, not editable source files.
- When updating the plan, keep dates, targets, and priorities explicit and easy to scan.

## Common tasks
- Update or refine a study timetable without breaking the plan’s structure.
- Add topic coverage, revision blocks, or practice sessions in a consistent order.
- Summarize progress, identify weak areas, and suggest next actions for TMUA preparation.
- Keep notes concise and action-oriented, especially when describing revision goals or problem-solving focus.

## Guidance for AI agents
- Prefer small, targeted edits over broad rewrites.
- Maintain a clear distinction between scheduled work, completed work, and upcoming priorities.
- If a task touches study content, keep it aligned with TMUA-style mathematics practice: algebra, calculus, problem solving, and reasoning under timed conditions.
- If a new file is created, choose a descriptive name that matches the study purpose and does not conflict with the existing plan structure.

## Repository status
This folder currently contains planning and resource materials, with no application build or test system in place. If code or scripts are added later, update this file with the relevant commands and conventions.
