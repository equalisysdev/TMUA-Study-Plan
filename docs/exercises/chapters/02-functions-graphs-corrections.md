# Corrections: Functions and Graphs

## Foundation

### 1. Evaluate
$$f(5)=11,\qquad f(-2)=-10.$$

### 2. Domain
Require $7-x\ge0$, so $\boxed{x\le7}$.

### 3. Range
$$(x-2)^2\ge0,$$ hence $\boxed{f(x)\ge1}$.

### 4. Transformation
$y=(x-3)^2-4$ is $y=x^2$ shifted $\boxed{3\text{ right and }4\text{ down}}$.

### 5. Vertex
$$-2x^2+8x-5=-2(x-2)^2+3,$$ so the vertex is $\boxed{(2,3)}$.

### 6. Intercepts
$$x^2-5x+6=(x-2)(x-3),$$ so the $x$-intercepts are $(2,0),(3,0)$ and the $y$-intercept is $(0,6)$.

### 7. Composition
$$f(g(x))=x^2+2.$$

### 8. Composition
$$g(f(x))=(x+2)^2.$$

### 9. Inverse
$y=4x+1$ gives $x=(y-1)/4$, so $\boxed{f^{-1}(x)=\frac{x-1}{4}}$.

### 10. Domain
The denominator cannot vanish: $x^2-9\ne0$. Thus $\boxed{x\ne\pm3}$.

## Core technique

### 11. Inverse
Let $y=(x-2)/(x+3)$. Then $y(x+3)=x-2$, so $x=(2+3y)/(1-y)$. Hence $\boxed{f^{-1}(x)=\frac{x+2}{1-x}}$.

### 12. Solve $f(x)=g(x)$
$$x^2-4=2x+1\implies x^2-2x-5=0,$$ so $\boxed{x=1\pm\sqrt6}$.

### 13. Range
$$x^2+6x+11=(x+3)^2+2,$$ so $\boxed{f(x)\ge2}$.

### 14. Minimum
$y=|x-2|$ has vertex $(2,0)$ and minimum $\boxed{0}$.

### 15. Solve
If $2x+1\ge0$, then $2x+1=x+4$, giving $x=3$. If $2x+1<0$, then $-2x-1=x+4$, giving $x=-\frac53$. Both work: $\boxed{x=3,-\frac53}$.

### 16. $x$-axis crossings
$$x^3-4x=x(x-2)(x+2),$$ so the points are $\boxed{(-2,0),(0,0),(2,0)}$.

### 17. One-to-one
$x^3$ is strictly increasing on $\mathbb R$, so $x^3+1$ is one-to-one.

### 18. Inverse value
$$f^{-1}(7)=\frac{7-3}{2}=\boxed2.$$

### 19. Find $f(x)$
Put $u=x+1$, so $x=u-1$:
$$f(u)=(u-1)^2+2(u-1)=u^2-1.$$
Thus $\boxed{f(x)=x^2-1}$.

### 20. Domain
Require $(x-1)/(x+2)\ge0$, with $x\ne-2$. A sign chart gives $\boxed{x<-2\text{ or }x\ge1}$.

## TMUA challenge

### 21. Transformation
A left shift by $2$ replaces $x$ by $x+2$; reflection in the $x$-axis changes the sign. New equation: $\boxed{y=-f(x+2)}$.

### 22. Intersections
$$\frac1x=x-2\implies x^2-2x-1=0,$$ so $x=1\pm\sqrt2$ and $y=x-2$. The points are $\boxed{(1+\sqrt2,-1+\sqrt2),(1-\sqrt2,-1-\sqrt2)}$.

### 23. Two roots in $(0,3)$
Let the roots be $r\le s$. Since $r+s=4$, the conditions $0<r$ and $s<3$ imply $1<r\le2$. For two distinct roots, $r<2$, and
$$
k=rs=r(4-r).
$$
This increases from $3$ towards $4$ as $r$ moves from $1$ towards $2$, so $\boxed{3<k<4}$. At $k=4$, the equation is $(x-2)^2=0$ and has only one distinct root; include $k=4$ only if repeated roots are counted.

### 24. Piecewise equation
For $x\ge0$, $x^2=4$ gives $x=2$. For $x<0$, $2x+1=4$ gives $x=\frac32$, invalid. Thus $\boxed{x=2}$.

### 25. Number of solutions
$$|x^2-4|=3\implies x^2=7\text{ or }x^2=1,$$
so $x=\pm\sqrt7$ or $x=\pm1$. There are therefore $\boxed4$ solutions.

### 26. Composition
$$f(f(x))=\frac{x/(1+x)}{1+x/(1+x)}=\boxed{\frac{x}{1+2x}},$$ with $x\ne-1,-\frac12$.

### 27. Additive function
For rational inputs, additivity and $f(1)=3$ give $f(q)=3q$. Thus $\boxed{f(5/2)=15/2}$.

### 28. Maximum
$$4x-x^2=4-(x-2)^2,$$ so on $[0,5]$ the maximum is $\boxed4$ at $x=2$.

### 29. Solve
$$x^2-2x=(3-x)^2-2(3-x)=x^2-4x+3.$$
Thus $2x=4x-3$, giving $\boxed{x=\frac32}$.

### 30. Inverse on $\mathbb R$
$f(x)=x^4+x^2+1$ is even: $f(x)=f(-x)$, so it is not one-to-one on all reals and has no inverse function there.
