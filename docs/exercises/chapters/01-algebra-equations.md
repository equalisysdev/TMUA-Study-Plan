# Chapter 1: Algebra and Equations

Complete without a calculator unless stated. Show a short method and check restrictions.

## Foundation
1. Expand and simplify `(2x-3)(x+5)`.
2. Factorise $x^2-9x+20$.
3. Simplify $(x^2-16)/(x^2-8x+16)$ and state restrictions.
4. Solve $5x-7=3x+9$.
5. Solve $x^2-7x+12=0$.
6. Solve $2x^2+x-6=0$.
7. Solve $(x-4)(x+1)>0$.
8. Solve $|3x-2|e 10$.
9. Find the remainder when $2x^3-5x+4$ is divided by `x-2`.
10. Given $a+b=9$ and $ab=14$, find $a^2+b^2$.

## Core technique
11. Solve $1/(x-1)+1/(x+1)=1$.
12. Find the values of `k` for which $x^2-6x+k=0$ has two distinct real roots.
13. Solve $x^2-5x+6 \\le 0$.
14. If $x+1/x=5$, find $x^2+1/x^2$.
15. Factorise $x^4-5x^2+4$.
16. Solve $\\sqrt{x+4}=x-2$.
17. Solve $2^(x+1)=16$.
18. Solve $log_2(x-1)=3$.
19. Find the coefficient of $x^2$ in $(1-2x)^5$.
20. For $x>0$, simplify $x^(3/2)/\\sqrt{x}$.

## TMUA challenge
21. Find the minimum value of $x^2-8x+19$.
22. Find all integers `n` for which $n^2-5n+6$ is prime.
23. If $x+y=5$ and $x^2+y^2=13$, find `xy` and the possible values of `x,y`.
24. Solve $|x-1|+|x+2|=7$.
25. Find all real `x` satisfying $(x^2-1)/(x^2+1)=1/2$.
26. Determine the number of real roots of $x^4-4x^2+1=0$.
27. If $p(x)=x^3+ax^2+bx+6$ has factors `x-1` and `x+2`, find `a` and `b`.
28. Find the largest possible value of `xy` if $x+y=10$ and $x,yge 0$.
29. Solve $3^(2x)-10(3^x)+9=0$.
30. For positive `a,b,c` with $a+b+c=1$, prove or disprove $ab+bc+cae 1/3$.
