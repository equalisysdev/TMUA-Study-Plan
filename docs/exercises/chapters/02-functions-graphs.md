# Chapter 2: Functions and Graphs

Sketch when useful. Always state domain restrictions where they matter.

## Foundation
1. If $f(x)=3x-4$, find `f(5)` and `f(-2)`.
2. Find the domain of $f(x)=\\sqrt{7-x}$.
3. Find the range of $f(x)=(x-2)^2+1$.
4. Describe the transformation from $y=x^2$ to $y=(x-3)^2-4$.
5. Find the vertex of $y=-2x^2+8x-5$.
6. Find the intercepts of $y=x^2-5x+6$.
7. If $f(x)=x+2$ and $g(x)=x^2$, find `f(g(x))`.
8. Find `g(f(x))` for the functions in question 7.
9. Find the inverse of $f(x)=4x+1$.
10. State the domain of $f(x)=1/(x^2-9)$.

## Core technique
11. Find the inverse of $f(x)=(x-2)/(x+3)$.
12. Solve $f(x)=g(x)$ for $f(x)=x^2-4$ and $g(x)=2x+1$.
13. Find the range of $f(x)=x^2+6x+11$.
14. Sketch $y=|x-2|$ and state its minimum.
15. Solve $|2x+1|=x+4$.
16. Find the points where $y=x^3-4x$ crosses the x-axis.
17. Determine whether $f(x)=x^3+1$ is one-to-one on the reals.
18. Find $f^{-1}(7)$ when $f(x)=2x+3$.
19. If $f(x+1)=x^2+2x$, find `f(x)`.
20. Find the domain of $\\\sqrt{\frac{x-1}{x+2}}$.

## TMUA challenge
21. The graph of $y=f(x)$ is shifted left 2 and reflected in the x-axis. Write the new equation.
22. Find all intersections of $y=1/x$ and $y=x-2$.
23. For what values of `k` does $x^2-4x+k=0$ have two roots in `(0,3)`?
24. If $f(x)=x^2$ for $xge 0$ and $f(x)=2x+1$ for $x<0$, solve $f(x)=4$.
25. Find the number of solutions of $|x^2-4|=3$.
26. If $f(x)=x/(1+x)$, find `f(f(x))` and simplify.
27. A function satisfies $f(x+y)=f(x)+f(y)$ and $f(1)=3$ for rational inputs. Find `f(5/2)`.
28. Find the largest value of $f(x)=4x-x^2$ on `[0,5]`.
29. For $f(x)=x^2-2x$, find the values of `x` for which $f(x)=f(3-x)$.
30. Determine whether $f(x)=x^4+x^2+1$ has an inverse on all real numbers; justify your answer.
