# Corrections: Trigonometry and Geometry

## Foundation

### 1. Exact values
$$\boxed{\sin\frac\pi6=\frac12,\quad\cos\frac\pi3=\frac12,\quad\tan\frac\pi4=1}.$$

### 2. Identity
$$\boxed{\sin^2x+\cos^2x=1}.$$

### 3. Solve
On $[0,2\pi]$, $\sin x=1/2$ at $\boxed{x=\pi/6,5\pi/6}$.

### 4. Solve
$\cos x=-1/2$ in quadrants II and III, so $\boxed{x=2\pi/3,4\pi/3}$.

### 5. Simplify
$$\boxed{\frac{\sin x}{\cos x}=\tan x},$$ where defined.

### 6. Gradient
$$m=\frac{10-2}{5-1}=\boxed2.$$

### 7. Midpoint
$$\boxed{\left(1,-2\right)}.$$

### 8. Distance
$$\sqrt{(4-1)^2+(6-2)^2}=\sqrt{25}=\boxed5.$$

### 9. Circle
The radius is $5$, so $\boxed{x^2+y^2=25}$.

### 10. Triangle area
$$\frac12(8)(5)=\boxed{20}.$$

## Core technique

### 11. Prove the identity
Divide $\sin^2x+\cos^2x=1$ by $\cos^2x$:
$$\tan^2x+1=\boxed{\sec^2x}.$$

### 12. Solve
$$2\sin x=\sqrt3\implies\sin x=\frac{\sqrt3}{2},$$ so $\boxed{x=\pi/3,2\pi/3}$.

### 13. Solve
$\sin(2x)=0$ means $2x=n\pi$. On $[0,\pi]$, $\boxed{x=0,\pi/2,\pi}$.

### 14. Simplify
$$\frac{1-\cos^2x}{\sin x}=\frac{\sin^2x}{\sin x}=\boxed{\sin x},$$ where $\sin x\ne0$.

### 15. Intersection
$$x^2-3=2x+1\implies x^2-2x-4=0,$$ so $x=1\pm\sqrt5$ and $y=3\pm2\sqrt5$. The points are $\boxed{(1+\sqrt5,3+2\sqrt5),(1-\sqrt5,3-2\sqrt5)}$.

### 16. Perpendicular bisector
The midpoint is $(3,1)$ and the original gradient is $1/3$, so the perpendicular gradient is $-3$. Thus $\boxed{y-1=-3(x-3)}$, or $\boxed{y=-3x+10}$.

### 17. Angle between lines
The slopes are $1$ and $-1$, so the lines are perpendicular: $\boxed{90^\circ}$.

### 18. Cosine rule
$$c^2=5^2+7^2-2(5)(7)\cos60^\circ=39,$$ so $\boxed{c=\sqrt{39}}$.

### 19. Area
The height is $\sqrt{5^2-4^2}=3$, so area $=\frac12(8)(3)=\boxed{12}$.

### 20. Complete the square
$$(x-3)^2+(y+2)^2=16,$$ so the centre is $\boxed{(3,-2)}$ and radius $\boxed4$.

## TMUA challenge

### 21. Solve
$\cos2x=1/2$ gives $2x=\pi/3,5\pi/3,7\pi/3,11\pi/3$ in the required range. Thus $\boxed{x=\pi/6,5\pi/6}$.

### 22. Prove
Using $\sin A+\sin B=2\sin((A+B)/2)\cos((A-B)/2)$,
$$\boxed{\sin x+\sin3x=2\sin2x\cos x}.$$

### 23. Maximum
$$3\sin x+4\cos x=5\sin(x+\alpha)$$ for suitable $\alpha$, so the maximum is $\boxed5$.

### 24. Intersections
Substitute $y=3$:
$$x^2+9=25\implies x=\pm4,$$ giving $\boxed{(-4,3),(4,3)}$.

### 25. Heron's formula
$s=12$, so
$$A=\sqrt{12(5)(4)(3)}=\boxed{12\sqrt5}.$$

### 26. Tangent
The radius gradient at $(3,4)$ is $4/3$, so tangent gradient is $-3/4$. Hence $\boxed{y-4=-\frac34(x-3)}$, or $\boxed{3x+4y=25}$.

### 27. Regular hexagon
Split into six equilateral triangles of side $2$:
$$6\left(\frac{\sqrt3}{4}2^2\right)=\boxed{6\sqrt3}.$$

### 28. Thales' theorem
If the centre is $O$ and the circumference point is $C$, then $OA=OB=OC$. The two base angles in each isosceles triangle are equal, and the angles around the centre sum to $180^\circ$ for the diameter, giving the angle at $C$ as $\boxed{90^\circ}$.

### 29. Area
$$\int_0^\pi\sin x\,dx=[-\cos x]_0^\pi=\boxed2.$$

### 30. Solve
Use $\cos2x=1-2\sin^2x$. Let $s=\sin x$:
$$s=1-2s^2\implies2s^2+s-1=0,$$
so $s=1/2$ or $s=-1$. Therefore $\boxed{x=\pi/6,5\pi/6,3\pi/2}$ on $[0,2\pi]$.
