# Trigonometry and Geometry Drills

## Learning objectives
- solve trig equations and use identities confidently
- handle coordinate geometry and line/curve problems
- reason with geometry and supplementary angle facts
- avoid algebraic slips in shaped problems

## Technique focus
- Learn common identities and rearrangements
- Always consider general solutions and principal ranges
- For geometry, draw a diagram before solving
- Use coordinate formulas efficiently

## Answer notes
- Question 1: recognise tangent identity
- Question 3: know standard sine values on the unit circle
- Question 4: solve cosine equation by isolating \\cos x
- Question 10: Heron’s formula or isosceles triangle area method
- Questions 6–9: use formulas repeatedly without friction
- Questions 12–15: practise angle and coordinate reasoning
