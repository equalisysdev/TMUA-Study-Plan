# Algebra and Functions Drills

## Learning objectives
- manipulate algebraic expressions accurately
- solve equations and inequalities efficiently
- recognise function transformations and graph behaviour
- interpret function notation precisely

## Exercise Set A: Algebraic manipulation

### 1. Simplify
$$
\frac{x^2-9}{x^2-5x+6}
$$

### 2. Solve
$$
3x^2 - 11x + 6 = 0
$$

### 3. Solve for x
$$
\frac{2}{x-1} = \frac{5}{x+2}
$$

### 4. Factor completely
$$
x^3 - 6x^2 + 11x - 6
$$

### 5. If \(x+y=7\) and \(xy=10\), find \(x^2+y^2\).

## Exercise Set B: Inequalities and quadratics

### 6. Solve
$$
(x-2)(x+3) > 0
$$

### 7. Solve
$$
|2x-5| \le 7
$$

### 8. Find the range of values of k for which
$$
x^2 - 4x + k = 0
$$

has real roots.

### 9. For what values of x is
$$
\frac{x+1}{x-2} < 0
$$

### 10. Given \(f(x)=x^2-4x+3\), find the vertex and axis of symmetry.

## Exercise Set C: Functions and graph transformations

### 11. Sketch the graph of
$$
f(x)= (x-1)^2 + 2
$$

and state the minimum value.

### 12. Describe the transformation from
$$
y=x^2 \text{ to } y = -2(x+3)^2 + 1
$$

### 13. If \(g(x)=3x-5\), find \(g^{-1}(x)\).

### 14. Find the domain of
$$
f(x)=\sqrt{x^2-9}
$$

### 15. If \(f(x)=x^2-1\) and \(g(x)=x+2\), find \(f(g(x))\).

## Technique focus
- Factor before simplifying
- Check for excluded values in rational expressions
- Treat inequalities carefully by sign analysis
- For functions, always note domain, range, and transformation

## Answer notes
- Question 1: factor and cancel common terms
- Question 2: solve by factoring or formula
- Question 3: cross multiply carefully; check restrictions
- Question 4: use rational root testing and factorisation
- Question 5: use \((x+y)^2 = x^2+y^2+2xy\)
- Questions 8–9: look for sign-based reasoning
- Questions 11–15: focus on transformation laws and inverse function logic
