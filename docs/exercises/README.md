# Exercise Bank

Use the [TMUA Study Portal](../website/index.html) for the interactive course route, or browse the complete [resource index](../resources.md) for explanatory lessons and all study materials.

The exercise bank is organised into six standalone chapters. Each chapter contains 30 exercises split into Foundation, Core technique, and TMUA challenge sections.

## Chapters
1. [Algebra and equations](chapters/01-algebra-equations.md)
2. [Functions and graphs](chapters/02-functions-graphs.md)
3. [Calculus and change](chapters/03-calculus-change.md)
4. [Trigonometry and geometry](chapters/04-trigonometry-geometry.md)
5. [Proof and logic](chapters/05-proof-logic.md)
6. [Combinatorics and probability](chapters/06-combinatorics-probability.md)

## Suggested use
- Foundation: learn and check the method.
- Core technique: solve cleanly without looking at notes.
- TMUA challenge: use a timer and write a short method justification.

Keep solutions and recurring mistakes in the error \\log template rather than writing over the question bank.
