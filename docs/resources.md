# TMUA Resource Index

This is the Markdown counterpart to the [TMUA Study Portal](website/index.html). Use it when you want to browse the same learning route as files and links.

## Explanatory courses

These are normal, lesson-style courses for learning or refreshing the underlying mathematics before attempting TMUA questions.

- [Khan Academy: Algebra](https://www.khanacademy.org/math/algebra) — expressions, equations, inequalities, and quadratics
- [Khan Academy: Precalculus](https://www.khanacademy.org/math/precalculus) — functions, graphs, transformations, and trigonometry
- [Khan Academy: Differential calculus](https://www.khanacademy.org/math/differential-calculus) — limits, derivatives, and optimisation
- [3Blue1Brown: The Essence of Calculus](https://www.3blue1brown.com/topics/calculus) — visual intuition for derivatives and integrals
- [Khan Academy: Geometry](https://www.khanacademy.org/math/geometry) — angles, similarity, circles, coordinates, and proofs
- [Khan Academy: Statistics and probability](https://www.khanacademy.org/math/statistics-probability) — probability rules, counting, distributions, and expected value
